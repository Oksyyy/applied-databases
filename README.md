# Conference Management Application
by Oksana Abrosimova

This repository contains a menu-driven Conference Management Application developed as part of the *Applied Databases* module. The application integrates both SQL and Neo4j databases to manage conference-related data including attendees, sessions, companies, rooms, and attendee networking connections.

The project demonstrates the use of:

* relational database operations using MySQL
* graph database operations using Neo4j
* SQL queries and aggregation
* Cypher queries
* user input validation and error handling
* menu-driven application design

---

# Technologies Used

* Python
* MySQL
* Neo4j
* PyMySQL
* Neo4j GraphDatabase Driver

---

## Requirements

The following Python packages are required:

* `pymysql`
* `neo4j`

---

## Running the Program

Run the application from the main file:

```bash
python main.py
```

Ensure:

* MySQL database is running
* Neo4j database is running
* database connection settings match your local environment
